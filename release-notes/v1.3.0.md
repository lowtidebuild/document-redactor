# document-redactor v1.3.0

_Released 2026-05-28_

This release focuses on keeping larger DOCX review and export flows responsive while preserving the same offline, deterministic redaction model.

## What's new

- **Faster preview toggles**: inline preview match positions are indexed once, so checking and unchecking candidates no longer repeats the same string search work.
- **Faster redaction**: selected literals share a compiled matcher, and automatic candidates use known scope hints before falling back to full-scope coverage for manual or unknown entries.
- **Faster analysis and verification**: DOCX scope artifacts are collected once per analysis flow, and repeated verification literals are deduplicated before scanning.
- **Performance smoke coverage**: focused tests now guard matcher reuse, preview index reuse, scope artifact reuse, and verification deduplication.
- **Neutral documentation examples**: public-facing examples use synthetic placeholders.

## Known limitations

- DOCX only. PDF and OCR still require different pipelines.
- The preview is review-oriented text, not a pixel-faithful Word layout clone.
- Performance work reduces repeated work in the current browser-thread pipeline; it is not yet a Web Worker or virtualized-preview rewrite.
- Verification still scans every relevant DOCX surface before a clean download is allowed.
